# Preview consumer sample

Copy this directory to a new isolated workspace and open it with Unity 6000.6.9f1.
The package registry and exact trial version are project configuration, not user
preferences. This sample uses the old trial version; the HTTPS verification also
checked an upgrade to `0.1.0-ze-pilot.2` and rollback by receiving only the two
package files. No publisher token, personal registry configuration or POB content
is included. Keep this as a trial; it is not a whole-project migration template.
